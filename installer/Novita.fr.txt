GGCalendar 1.0.3 - Nouveautés
=============================

  - Choix de la police de caractères de l'application ;
  - La description d'un événement affiche le gras, l'italique, le souligné, les titres, les listes et les liens ;
  - Les adresses web et les e-mails de la description sont cliquables ;
  - Recherche améliorée (écarte les balises cachées) ;
  - Les événements peuvent avoir des pièces jointes (liens https vers des fichiers) ;
  - Partage d'événements individuels via les applications les plus courantes.
